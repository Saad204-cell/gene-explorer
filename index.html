About

Gene Explorer is a free pocket app for biotechnology students. It was built by Saad, a final-year BS Biotechnology student at Riphah International University, Faisalabad.

GitHub: Saad204-cell

Data sources

  • UniProt: gene and protein facts, protein sequences
  • Ensembl: coding sequences
  • NCBI: coding sequences when Ensembl has none
  • AlphaFold Protein Structure Database: predicted 3D structures
  • 3Dmol.js: the 3D structure viewer

Gene lookup needs internet. The Toolkit and Learn tabs use no outside data and work offline once the app has been opened once.

Install on your phone

Android (Chrome): tap the Install button above, or the ⋮ menu → "Install app" / "Add to Home screen".

iPhone (Safari): tap the Share button → "Add to Home Screen".
